## 执行约定（由 PRD/计划导出）

1. 核心安全流程：生成 SQL → 展示给用户审核（可修改）→ 用户确认 → 才执行查询，任何环节不得绕过审核直接查库。
2. 问数通道默认只读：写操作被只读保护直接拦截；数据更新仅通过"上传"入口。
3. 轻量化优先：仅使用上表选定的依赖，不引入额外框架。
