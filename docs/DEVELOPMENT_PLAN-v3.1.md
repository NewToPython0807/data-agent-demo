## 2. 范围

### 2.1 包含（PRD v3.1 §5）

- FR-1 澄清分级（`ambiguities` 对象化 + `is_blocking`）
- FR-2 非阻塞歧义自动继续
- FR-3 消费口径强制化 + 后置校验 + 重试
- FR-4 比率单位统一（小数）
- FR-5 物理删除 9 张测试表 + 测试指标
- FR-6 指标同义词匹配
- FR-7 澄清卡片体验
- FR-8 拒答/澄清分流
- FR-9 80 条转 golden 回归
- FR-10 造数账单/还款对齐 + 指标修正

### 2.2 不包含

- 多模型、RBAC、审计、图表、MCP/IM、向量召回等（见 PRD §3.2）。

## 9. 依赖与风险

### 9.1 依赖

- V3 代码库与 `eval_v2/cases_v2.json`（80 条用例）；
- DeepSeek API Key、本地/云端服务；
- 用户确认 D1–D7 已定。

### 9.2 风险

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| `is_blocking` 规则误判 | 该澄清未澄清/过度澄清 | 用 80 条回归校准关键词 |
| 消费口径校验误报 | 正常 SQL 被重试 | 仅检测明确消费意图；重试 1 次 |
| 比率前端格式化 | CSV 导出差异 | 前端格式化、导出保留小数 |
| 物理删表不可逆 | 演示数据丢失 | 执行前备份；可重跑 `seed_data_v2.py` 恢复 4 表 |
| 造数重写 | 参考结果变化 | 重跑 golden/评测 |
| 旧历史兼容 | 计划卡片异常 | 字符串归一为 assumption |
| 云端部署 | 数据/语义层不一致 | 重新造数 + 检核 |
