## 2. 第二版范围与不包含

### 2.1 包含（对应 PRD v2 §4.1）

1. **指标/语义层定义模块**：表/字段中文名 + 指标定义（名称/口径/说明/关联表字段/单位/适用维度），网页表单手工维护，**指标保留变更历史**。
2. **复杂查询**：10 万行以内，支持**多表关联、聚合后筛选（HAVING）、窗口函数**；JOIN 键由 AI 推断，代码**预留表关系扩展点**。
3. **前端三段式**：左导航（数据表/指标/历史/设置）/ 中对话流 / 右结果区。
4. **结果导出 CSV**：仅导出**当前查询结果**。
5. **测试造数**：3–5 张表 × 每表 1–10 万行（细节测试阶段定）。

### 2.2 不包含（PRD v2 §4.2 暂不做）

- 行级/列级权限、大模型可切换、多用户 RBAC
- VPN/专线、CI/CD、监控告警、备份
- 接入公司现有数据库
- 报表/看板/订阅、AI 自动洞察
- 语义层的同义词与表间关联关系定义
- 图表可视化
- 指标 Excel/JSON 批量导入
- 多租户 SaaS

## 9. 依赖与风险

### 9.1 依赖

- **技术依赖**：V1 现有代码库（FastAPI/SQLite/DeepSeek）、造数脚本。
- **环境依赖**：沿用现有腾讯云服务器。
- **数据依赖**：测试造数（T23）。
- **决策依赖**：PRD v2 §9 决策已确认，无阻塞。

### 9.2 风险与缓解

| 风险 | 影响 | 缓解措施 |
| --- | --- | --- |
| 多表 JOIN 键靠 AI 推断，准确率有上限 | 复杂关联可能生成错误 SQL | 用户可审核修改 SQL；预留表关系扩展点；测试用例覆盖典型关联 |
| 10 万行窗口函数/多表关联耗时 | 页面等待偏长 | 不设硬指标，实测记录；必要时给表加索引 |
| 指标口径维护偏差 | 问数结果与业务不符 | 指标口径可编辑 + 变更历史；测试阶段核对 |
| 前端三段式改版影响 V1 交互 | 回归风险 | T28 回归测试；V1 可回退 |
| 部署新增表与 V1 数据迁移 | 数据兼容风险 | 幂等建表（`IF NOT EXISTS`），不删不改 V1 表；部署前备份 `data/` |
