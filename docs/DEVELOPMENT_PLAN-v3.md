## 2. 第三版范围与不包含

### 2.1 包含（PRD v3 §4.1）

1. **V3-1 语义层增强**：同义词/业务术语 + 表关系（JOIN 键）+ 业务上下文（口径说明、弃用表、注意事项）。
2. **V3-2 查询可信**：歧义澄清 + 执行失败自动纠错 + golden SQL 示例库 + 结果校验/异常提示。
3. **V3-2b 查询计划展示**：生成 SQL 前输出结构化"分析过程"，前端可折叠展示，并随历史存储。
4. **V3-2c 超范围拒答**：核心数据不存在且无法推导时，直接拒答。
5. **V3-4 评测与反馈（轻量）**：结果赞/踩 + golden queries 回归脚本 + 简单统计接口。

### 2.2 不包含（PRD v3 §4.2）

- 图表可视化、数据源接入、多用户/权限、审计、集成/运维/知识记忆/多租户。

## 9. 依赖与风险

### 9.1 依赖

- V2 现有代码库、seed 数据（`seed_data_v2.py`）。
- 云端服务器（沿用）。
- 决策：PRD v3 §9.2 已给默认值（D1–D6）。

### 9.2 风险与缓解

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| 计划 JSON 解析失败 | 流程中断 | 正则兜底/降级为文本；解析失败走普通生成 |
| 拒答过度或不足 | 误拒/漏拒 | 用 golden 用例校准；D6 边界规则 |
| 澄清交互复杂 | 体验差 | 简化：默认"按假设继续"，歧义可选 |
| 延迟增加（计划+纠错+澄清） | 等待变长 | UI 显示"分析中"；必要时合并调用 |
| 表关系维护成本 | 语义层维护负担 | 可选维护；未维护回退 AI 推断 |
| V2 回归 | 功能退化 | T27 回归测试 |

## 10. 后续版本建议（不进入本版）

- 图表可视化、数据源接入、多用户/权限、审计。
- 两次调用（计划与 SQL 分离）、候选表/指标召回（大 schema）。
- MCP/IM 集成、运维自动化、分层记忆/数据图谱、多租户/SSO。
